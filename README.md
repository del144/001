# Журнал успеваемости

Учебный журнал: список студентов, группа, баллы, посещаемость и фильтр на стипендию.

## Запуск


```bash
python -m venv .venv
# Linux/macOS:
source .venv/bin/activate
# Windows PowerShell:
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

## Cоответствие заданию

- Основная сущность `Student` наследуется от абстрактного класса `Entity` из `common.py`.
- Все поля модели имеют геттеры/сеттеры через `@property`.
- Реализованы `__eq__`, `__repr__`, `__str__`, `__lt__`, `__len__`, `__bool__`; экземпляры можно сравнивать.
- `EntityMap` — собственный класс отображения на базе списка пар, вместо встроенного `dict`.
- `ui_components.py` содержит более 10 пользовательских Qt-виджетов с переопределенными обработчиками событий.
- Форма использует выравнивающие layout-контейнеры Qt; данные предметной области представлены объектами классов.
- При первом запуске создаются 10 демонстрационных объектов. Добавление и удаление записей сохраняется в CSV.
- При закрытии окна создаётся `data/session_report.txt`; даты в отчёте имеют формат `%d.%m.%Y %H:%M:%S`.

## Основные файлы

- `main.py` — окно приложения, действия пользователя и CSV-репозиторий.
- `models.py` — класс предметной сущности.
- `common.py` — абстрактная сущность, `EntityMap`, сеанс работы и формирование отчёта.
- `ui_components.py` — переопределенные виджеты и общая тема интерфейса.
